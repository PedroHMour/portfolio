# Portfolio (freelas)

Astro + Tailwind v4, em português, inglês e francês.

    npm install
    npm run dev      # http://localhost:4321
    npm run build    # gera dist/

## O que editar
- `src/i18n/ui.ts`: textos dos 3 idiomas e seus dados de contato (`profile`)
- `src/data/projects.ts`: projetos e tecnologias
- `astro.config.mjs`: `site` (troque pelo domínio real, usado em SEO e sitemap)
- `public/`: foto (`profile.png`) e currículo (`cv.pdf`)
